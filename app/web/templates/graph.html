  1. Open the Microsoft Entra admin center → App registrations → New registration.
  2. Name it (e.g. internship-finder). Under Supported account types pick Personal Microsoft accounts only, then Register.
  3. Go to Authentication → Add a platform → Mobile and desktop applications, tick https://login.microsoftonline.com/common/oauth2/nativeclient, set Allow public client flows to Yes, and Save.
  4. Go to API permissions → Add a permission → Microsoft Graph → Delegated permissions → add Mail.Send and Mail.Read.
  5. Copy the Application (client) ID from the Overview page and paste it into Settings, then come back here.
